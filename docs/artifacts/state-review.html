08 · instrument

How this page is kept honest

Two user behaviours depend on the contract, and both used to fail silently. Now one command replicates them on demand.

$ scripts/state-health.py --all ok aliases agree: scripts/workspace-state.py ok aliases agree: scripts/open-workspace.sh ok aliases agree: terminal.lua ok STATE.md front matter · has a diagram · TODO sections · backlinks resolve ok smoke: injects in-flight work, next steps, latest decision, latest commit ok smoke: omits the backlog and superseded journal entries ok smoke: launcher resolves the state doc · silent without a contract ok STATE.md matches the code — verified 2026-08-10 WARN two repos have no state doc — copy templates/STATE.md 14 ok, 2 warn, 0 fail — 4 repo(s)
  • sanity  Is it wired? Front matter, a diagram present, the three TODO sections, backlinks that resolve, and the state-doc alias list agreeing across its python, bash and lua copies — three runtimes that cannot share a constant.
  • smoke  Does the behaviour work? Drives the real hook and launcher against a throwaway git repo and asserts a fresh session could catch up.
  • drift  Has the code moved without the doc? Counts commits after last-verified that touch something other than markdown. A doc edit cannot clear it — only re-verifying can, which is the whole point.
