## 1. fix-friction-system-prompts

**1. R: the Stop-time join between telemetry prompt events and transcript entries is undefined (README:24, root cause, AC-1).** The Stop scorer reads the telemetry session JSONL. Each prompt event there carries only `ts` (local offset), `classification` and `prompt_text`, truncated to 1000 characters plus "..." (log-prompt.ps1:46-53). The spec says "label each prompt from the transcript's `promptSource`" but names no join key. `prompt_id` is not safe: in the live transcript `22cfd953…jsonl`, promptIndex 1 and 2 are different typed prompts that share the same `promptId` (`48df4778…`), and log-prompt.ps1 does not store `prompt_id` today. The timestamps differ in format (transcript `Z`, telemetry `-08:00`). Identical or truncated texts would collide, and sidechain entries (`isSidechain`) also exist in the transcript. So the core mechanism is unspecified, and AC-1 can pass with any join that happens to work on its own fixture. Fix: name the join (for example a UTC-normalised timestamp window plus a text-prefix match, with a defined tie order), state the `unlabelled` fallback outcome, and add a fixture where two prompts share text or a `promptId`. Gap category: new: unspecified-join-key. Class: design.

**2. R: AC-1 and AC-7 test `analyze-session.ps1`, which cannot be tested as specified (README:66, 72).** The script is a monolith. It reads stdin and uses hard-coded `$HOME\.claude\telemetry\…` paths (lines 36, 39, 187, 222, 236, 307, 340), writes the cost ledger and `cumulative.json`, and plays sounds. The existing `tests/classification.tests.ps1` only dot-sources pure functions, and the AC names that file with no HOME override or extracted scorer function. Run as written, the test would pollute the real counters (`cumulative.json` is at 251 right now and drives the retrospect nag). Otherwise it would exercise only a helper, leaving the "scored at Stop" path untested. Fix: say that the scorer is extracted into a pure function in lib/classification.ps1 with paths injected, or give the HOME-override fixture. Keep an end-to-end check that `report.transcript_path` and `marker_misses` come out of the real script. Gap category: untestable-AC. Class: test.

Fix: put all five `promptSource` values in the fixture and assert the report counts. Class: test.
